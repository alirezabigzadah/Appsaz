## 📖 About

**Appsaz** is an Android application builder that lets users create and customize Android apps without requiring programming knowledge.

It includes tools for managing pages, lists, images, fonts, animations, backgrounds, and other application resources. Appsaz can also generate APK files and provides tools for creating or importing Java KeyStore (JKS) files and signing applications.

This repository contains the Appsaz source code for anyone interested in studying, modifying, or contributing to the project under its license.

## ✨ Features

### 📱 Application Creation

- Create and manage Android application projects.
- Add and customize application pages.
- Create and manage lists.
- Configure application settings and appearance.

### 🎨 Design and Media

- Manage images and other media files.
- Add custom fonts and backgrounds.
- Use animations and visual effects.
- Create application icons with the built-in icon maker.

### 📦 APK Building

- Generate Android APK files.
- Configure application build settings.
- Sign generated APK files for installation and distribution.

### 🔐 Keystore Management

- Create new **Java KeyStore (JKS)** files.
- Import existing JKS keystores.
- Configure keystore and key credentials.
- Use keystores for Android application signing.
- Support APK signing schemes **V1, V2, V3, and V4**.

### 📢 Advertising and Languages

- Google AdMob banner advertisement integration.
- Multilingual application interface.

## 🚀 Getting Started

### Requirements

- Android Studio
- Android SDK required by the project
- Compatible JDK
- Git (optional if downloading the ZIP)

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/alirezabigzadah/Appsaz.git
   ```

2. Open the cloned project directory in **Android Studio**.
3. Allow **Gradle Sync** to complete, and install any required Android SDK components.
4. Connect an Android device or launch an emulator, then build and run the app.

## 🔑 APK Signing and Keystores

Appsaz can create a JKS keystore or import an existing one for signing generated Android APKs.

| Signing scheme | Support |
| --- | :---: |
| V1 (JAR signing) | ✅ |
| V2 (APK Signature Scheme) | ✅ |
| V3 (APK Signature Scheme) | ✅ |
| V4 (APK Signature Scheme) | ✅ |

> **Important:** Store keystores and passwords securely. Losing an application's signing key can prevent future updates in some distribution configurations. Never commit real signing credentials to this repository.
